# 残余风险修复

- HIGH-01：IndexedDB 事务绑定页面打开时的持久代际。每次学习库写事务先在同一事务中校验代际，过期则中止。禁用 Web Locks 的独立 Edge 测试通过。
- HIGH-02：主库从 v3 非破坏性升级至 v4。原始 v0.5.2 代码在升级后重新打开 v3 时收到 VersionError。升级阻塞时放弃请求并中止迟到升级。
- MED-01：补做起始日期与首次有效任务或已有完整任务在同一事务中写入。范围不足的重复启动测试先失败后通过。
- MED-02：更新不主动 skipWaiting，等待旧客户端自然退出。客户端枚举后的新页面无法触发强制接管。
- 变更后应用 0.5.3，DB 4，缓存 grade7-math-v36，题库版本 2026.10.368。题库 SHA-256 保持 13cdefaeca70001581c0e33cc93ec0f2a5c4194d30cf11b99dac5d4211ec90d5。
