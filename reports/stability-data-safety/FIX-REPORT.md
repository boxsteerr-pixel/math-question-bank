# 专项修复说明

## BUG-01 备份恢复

修改 `js/backup.js`、`js/db.js`、`js/parentDashboard.js` 和 `tests/backup-restore.js`。恢复先验证主键类型、唯一性、必要字段和任务、题目关联。独立 IndexedDB 保存恢复前的完整快照，并在读取校验后才允许继续。在同一写事务中核对数据没有被其他窗口修改，逐表替换并比对内容。任何提交前错误触发中止。提交后再次读取并比对。家长模式可导出恢复点，也可使用恢复点回退。备份格式仍为 1。

回归覆盖 12 组备份场景，另在隔离 Edge 使用真实 IndexedDB 验证回退、写入异常和事务中止。当浏览器支持 Web Locks 时，恢复会独占学习会话，仍打开的练习页会阻止恢复。缺少该接口的浏览器需要先手动关闭其他练习页。快照依赖站点存储，如果浏览器清理站点数据或存储空间不足，仍可能丢失快照或阻止后续恢复。

## BUG-02 学习范围和历史任务

修改 `js/questionEngine.js`、`js/app.js`、`js/parentDashboard.js` 与相关测试。两端按实际可用的不同题目 ID 显示数量，只允许保存至少 10 道的选择。保持原选择器的规则，只有未填满的任务才用同一已选范围内的剩余题补足。验证任务后原子写入任务和历史。旧任务有草稿、答案、开始状态、订正或打卡证据时保留，界面提示导出并人工核查，同时保留其他有效任务的入口。补做范围内未提交的异常任务仍阻止提前打卡。可修复旧任务的历史计数只做有归属依据的修正。

范围边界、历史设置和补做的隔离模拟通过。实际 Edge 验收验证了短范围禁止保存、未作答旧任务恢复、原草稿逐表保留和设置写入失败回滚。无法确定归属的旧历史计数保留原值。

## BUG-03 PWA 安全更新

修改 `service-worker.js`、`js/updateManager.js`、`js/app.js`、`js/parentDashboard.js`、`js/version.js` 和发布测试。新 Worker 安装后等待。应用按页面、未提交输入、保存和提交状态限制更新。允许更新时仍验证请求页为范围内唯一打开的页面。Worker 保留前一份完整缓存，并按当前文档使用的版本供给静态文件。用户从 v34 首次迁移时，保存后关闭所有旧页面再重新打开。首装和下载失败均无强制刷新。

隔离 Edge 验证了真实 v34 → v35、后续受控升级、多窗口、断网、失败后重试和订正草稿。历史线上 v34 的版本文件已核对。未使用 iPad Safari 实机。
