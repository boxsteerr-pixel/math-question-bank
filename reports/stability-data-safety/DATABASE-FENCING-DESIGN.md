# 数据库隔离设计

主库 v4 新增 learningMetadata，learningDataGeneration 与备份中的 settings 分离。打开页面时固定当前代际。openDB 的写事务代理将元数据 store 纳入每个写事务，在同事务中先读取并核对代际，过期时中止事务并通知页面。put、setMany、设置保存、迁移、任务生成、历史、草稿、答题、统计、错题及打卡均通过该连接创建事务。独立快照数据库仍独立于被替换的学习数据。

恢复事务在替换学习数据的同一事务中递增代际，并执行完整内容校验。异常中止同时回滚数据与代际。两个同代恢复竞争时仅一个可提交。成功恢复的页面重新载入以获取新的代际，旧页面拒绝后显示提示并允许复制未保存输入。

v3 → v4 只添加元数据 store，保留原有 store。旧版 0.5.2 使用固定 v3 打开，升级后无法重新打开。回退需使用兼容 v4 的修复程序，不可直接回退 v0.5.2、降级或删除数据库。旧连接阻塞升级时应关闭旧页面后重试。
