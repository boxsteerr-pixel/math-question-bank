# 七年级数学每日计算打卡

这是一个可离线使用的每日练习 PWA，也包含题库整理和人工审核工具。当前正式题库有 **368 道**，题目 ID 为 Q0001 至 Q0368，题库版本为 **2026.10.368**。正式题来自多批 PDF 与 DOCX，来源及题面、答案位置随题记录。

正式题库位于 [data/questions.json](data/questions.json)，版本由 [js/version.js](js/version.js) 统一管理。发布测试会核对题量、ID、版本尾段和题库 SHA-256。

## 练习与学习范围

- 每天新开一组 10 道不同的题。前 5 个打卡日为诊断阶段，之后按弱项强化、普通复习、错题回炉的 5＋3＋2 规则分配，具体比例随可用样本和到期错题调整。
- 在首页或家长模式可以选择已学习的知识点。页面显示已选项、可用正式题目和缺少的题数。至少有 10 道可用题才可保存，已生成的完整任务继续沿用原题和原判分策略。
- 换日后，原有任务和草稿按组保留。未提交的组顺延补做。当所有待提交组提交后，记录实际完成日的打卡。
- 首次做错的题按照 D+1、D+4、D+7 回炉，连续三次复习正确后标为已掌握。再次错答会重启该题的回炉周期。
- 已经作答的不完整旧任务需要人工核查。可继续完成其他有效任务，并在家长模式导出完整备份以协助核查。

当前支持相反数、绝对值、去括号、添括号、合并同类项、整式加减综合、因式分解（提公因式法、平方差公式、完全平方公式、综合方法）、同底数幂乘法、同底数幂除法、幂的乘方、积的乘方、幂的运算综合、单项式乘法、多项式乘多项式、乘法公式、整式乘法综合、整式乘除综合、整式化简求值。

## 备份与更新

学习记录保存在当前浏览器。家长模式可导出完整 JSON 备份。还原时先检查预览并确认覆盖。其他页面如果仍持有旧数据，将被阻止写入，并提示重新载入。覆盖前应用会保存并核验一份独立的本机快照，然后原子地替换和校验学习记录。家长模式支持导出该快照或使用它回退。清除浏览器站点数据可能同时移除本机记录和快照，重要备份请另存为文件。

新版本下载后会等待。请保存各页面的练习，关闭所有数学打卡页面，再重新打开完成更新。首次从 v0.5.2 升级时，请保存并关闭所有旧页面后重新打开。数据库将升级至版本 4。v0.5.2 无法打开版本 4 数据库，遇到问题时需使用兼容数据库版本 4 的修复程序。已安装的版本在更新下载失败时可以继续使用。

## 本地启动与验证

在仓库根目录运行以下命令，再打开 `http://localhost:4173/`。

```sh
python -m http.server 4173
```

验证需要 Node.js、npm、可用于升级夹具的 Git 历史，以及安装了 Playwright 的环境和 Chromium 浏览器。可以用 `PLAYWRIGHT_MODULE_ROOT` 和 `PWA_TEST_BROWSER` 指定本机路径。浏览器测试使用独立会话和回环地址。

```sh
npm test
npm run test:pwa
node tests/learning-range-browser.mjs
node scripts/validate_questions.js
git diff --check
```

## 题库与审核

- [question-preview.html](question-preview.html) 只读显示正式题面和答案。
- [review/review.html](review/review.html) 用于人工审核，支持本地保存和导出审核进度。正式应用使用审核通过后写入 `data/questions.json` 的数据。
- `source/` 保存原始来源，`tools/` 保存处理脚本，`reports/` 保存分批审核和验收证据。
